## エージェントモデルを更新

openteams は各 Agent CLI または ACP ランタイムが報告するモデル一覧を読み取ります。モデル ID を手動で追加しても基盤の CLI にモデル対応は追加されないため、エージェントページでは手動追加できません。

<Steps>
<Step>
`設定 -> Agents` ページを開きます。
![エージェント設定に入る](../../images/en/agent_setting.png)
</Step>
<Step>
Agent を選択し、**モデル**フィールド横の**モデルを更新**をクリックします。openteams がインストール済みの CLI または ACP ランタイムを再照会し、モデル一覧を更新します。
</Step>
<Step>
Agent を選択し、**モデル**フィールドから検出済みモデルを選択します。
</Step>
</Steps>

ページ右上の更新ボタンは Agent 設定を更新するもので、モデル一覧の更新には使用しません。

openteams CLI などプロバイダー経由のランタイムでは、`設定 -> Service Providers` でモデルを設定します。Agent のモデル一覧は自動的に同期されます。
