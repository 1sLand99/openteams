## 에이전트 모델 새로고침

openteams는 각 Agent CLI 또는 ACP 런타임이 보고한 모델 목록을 읽습니다. 모델 ID를 수동으로 추가해도 기본 CLI에 모델 지원이 추가되지 않으므로 에이전트 페이지에서는 수동 추가를 지원하지 않습니다.

<Steps>
<Step>
`설정 -> Agents` 페이지로 이동합니다.
![에이전트 설정 진입](../../images/en/agent_setting.png)
</Step>
<Step>
Agent를 선택한 다음 **모델** 필드 옆의 **모델 새로고침**을 클릭합니다. openteams가 설치된 CLI 또는 ACP 런타임을 다시 조회하고 모델 목록을 업데이트합니다.
</Step>
<Step>
Agent를 선택한 다음 **모델** 필드에서 검색된 모델을 선택합니다.
</Step>
</Steps>

페이지 오른쪽 위의 새로고침 버튼은 Agent 구성을 새로고침하며 모델 목록을 새로고침하지 않습니다.

openteams CLI처럼 서비스 공급자가 모델을 제공하는 런타임은 `설정 -> Service Providers`에서 모델을 구성합니다. Agent 모델 목록은 자동으로 동기화됩니다.
