## 刷新 Agent 模型

openteams 会读取各 Agent CLI 或 ACP 运行时报告的模型列表。Agent 页面不支持手动添加模型 ID，因为这不会让底层 CLI 获得相应模型能力。

<Steps>
<Step>
进入 `设置 -> Agents` 页面
![进入代理设置](../../images/zh/agent_setting.png)
</Step>
<Step>
选择 Agent，然后点击**模型 ID**字段旁的**刷新模型**。openteams 会重新查询已安装的 CLI 或 ACP 运行时并更新模型列表。
</Step>
<Step>
选择 Agent，然后在**模型 ID**字段中选择已发现的模型。
</Step>
</Steps>

页面右上角的刷新按钮用于刷新 Agent 配置，不用于刷新模型列表。

对于 openteams CLI 等由服务供应商提供模型的运行时，请在 `设置 -> 服务供应商` 中配置模型；Agent 模型列表会自动同步。
