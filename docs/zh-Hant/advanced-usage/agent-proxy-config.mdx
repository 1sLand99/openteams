## 重新整理 Agent 模型

openteams 會讀取各 Agent CLI 或 ACP 執行環境回報的模型清單。Agent 頁面不支援手動新增模型 ID，因為這不會讓底層 CLI 取得相應模型能力。

<Steps>
<Step>
進入 `設定 -> Agents` 頁面
![進入代理設定](../../images/zh/agent_setting.png)
</Step>
<Step>
選擇 Agent，然後點擊**模型**欄位旁的**重新整理模型**。openteams 會重新查詢已安裝的 CLI 或 ACP 執行環境並更新模型清單。
</Step>
<Step>
選擇 Agent，然後在**模型**欄位中選擇已探索到的模型。
</Step>
</Steps>

頁面右上角的重新整理按鈕用於重新整理 Agent 設定，不用於重新整理模型清單。

對於 openteams CLI 等由服務供應商提供模型的執行環境，請在 `設定 -> 服務供應商` 中設定模型；Agent 模型清單會自動同步。
